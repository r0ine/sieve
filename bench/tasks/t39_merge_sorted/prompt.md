# merge sorted

Difficulty: medium

Write `solve(left: list[int], right: list[int]) -> list[int]`.

Both inputs are sorted ascending. Return all elements in one ascending list, including duplicates. Neither input is mutated. Empty inputs are allowed.

Examples:
- `solve([1, 3], [2, 3]) == [1, 2, 3, 3]`
- `solve([], [-1]) == [-1]`
