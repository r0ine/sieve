# frequency rank

Difficulty: medium

Write `solve(values: list[int]) -> list[int]`.

Return distinct integers sorted by descending frequency, then by ascending numeric value for equal frequencies. Empty input returns [].

Examples:
- `solve([3, 1, 3, 2, 2]) == [2, 3, 1]`
- `solve([-1, 2, -1, 2]) == [-1, 2]`
